The included PDFs contain examples of common stamps that you might typically
use as an AO/AR. To create your own "stamps," create a document in Word,
Google Docs, or another document editor with the text and formatting you want
to overlay, then save or export the document as a PDF.

Multiple files can be overlaid by listing each file, separated by a space.

The -a option applies the overlay to all pages.
The -e option applies the overlay once per event:
  --first applies the overlay to the first page in the series for an event.
  --last applies the overlay to the last page in the series for an event.
  The default is --first if neither option is specified.
